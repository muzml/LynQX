# LynQX - Streamlining Your Testing Process

LynQX is an AI-powered automation tool designed to take user stories, break them down into test scenarios, review them, generate full test cases, verify coverage, and finally prepare for test execution and report generation.

## 🛠️ Step-by-Step QA Workflow

1. **Input User Story**: Enter text or upload requirements file.
2. **Generate Test Scenarios**: Generates positive, negative, and edge cases using Llama 3.
3. **Review Scenarios**: Approve, reject, or delete individual scenarios.
4. **Create Test Cases**: Enter test steps and expected results for approved scenarios.
5. **Verify Coverage**: Visually check metrics on which requirements are fully covered.
6. **Prepare for Execution**: Run a pre-test check and export your test suite in JSON format.
7. **Upload Test Results**: Record passing or failing outcomes for each test case.
8. **Generate Report**: Review execution summaries, pass rates, and download report logs.
